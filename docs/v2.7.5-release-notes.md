## 2. Fixes

### 2.1 Force verbs match by object proximity

Verbs are now split by intent:

- **ATTACK** (shoot, fire, stab, attack, punch, swing, blast, breach, aim,
  smash) — harms people; a bare attack with no named target keeps the
  nearest-NPC fallback.
- **FORCE** (kick, break, ram, shoulder, barge, burst, force) — breaks
  things; rolls STR (or firearm skill with gun + ballistic phrasing) when a
  breakable object is in the phrase (door, lock, latch, window, hatch,
  padlock, deadbolt, barricade, chain, handcuffs, bulkhead, gate), and
  rolls NOTHING when there isn't one. *"Break the news to her"* is not an
  assault — force verbs never get the NPC fallback.

### 2.2 The mandatory request, in plain terms

The system prompt now states: narrating the setup of a risky action without
a matching `dice_requests` entry in the SAME response is "a defect, not
pacing." The setup-only rule exists to buy ONE beat for a roll — not to
admire the tension.

## 3. The meter

The question was "how do we measure the actual cost per prompt?" The
provider already meters every call — the response's `usage` object. Now the
engine keeps it:

- `logs/llm_timing.jsonl` records `pt` (prompt tokens), `ct` (completion
  tokens), and `cached` (cache-hit prompt tokens) per attempt, when the
  provider reports them.
- `--debug` echo gains the live count: `tok=2100+780`.
- `python test_latency.py --report` prints a tokens & estimated cost block:

```
  model            calls      tok in    cached   tok out     ~cost
  ---------------------------------------------------------------
  kimi-k2.6            2      14,732     4,000     2,451   $0.0206
  kimi-k3              1       7,200         0     1,400   $0.0426
  TOTAL                3      21,932     4,000     3,851   $0.0632
```

Rates live in `config/settings.json -> pricing` (shipped with Moonshot's
published per-1M-token rates; edit to match your plan). Rows from before
v2.7.5 and models without rates are counted, never costed.

First reading from the maintainer's own log: two k2.6 turns ≈ $0.021, one
k3 turn ≈ $0.043. A 20-turn solo session on the default tier is pocket
change; heavy tier is a deliberate purchase, which is what
`heavy_escalation` is for.
