# CoC 7e LLM Keeper — v2.7.3 "Weapon-Skill Truth + The Equipment Menu"

Release notes, July 20, 2026. Covers v2.7.2 -> v2.7.3 (per-weapon firearm
skills, inventory system, weapon instancing). Verified offline:
test_engine.py 211 checks + test_charcreate.py 64 checks, both ALL TESTS
PASSED, plus fresh-extraction verification of the shipped zip. Regression
tests preceded every fix.

## 1. The design question that shaped this release

Player feedback: "the more user prompt freedom the more variables it
creates — maybe there should be an in-game equipment menu? I don't want
players typing {SHOOT_GUN} and losing the nuance of the TTRPG."

The answer is a two-channel architecture, now explicit:

- **Narrative channel** — free text, always. The preroll net catches common
  verbs (and widens cheaply with each field log), `dice_requests` covers
  the long tail, and the fiat-ban + commitment rule keeps the model honest.
- **System channel** — typed commands the engine owns: `quit`, and now
  `inventory` / `equip` / `unequip`. Gear is state, not prose.

## 2. Fixes

### 2.1 Per-weapon firearm skills (the deferred bug, now dead)

`resolve_attack` rolled every firearm off `Firearms_Handgun`. A character
with `Firearms_Rifle_Shotgun 50` and no handgun training fired their
12-gauge at the 20% base. The weapon in hand now decides the skill —
shotguns use Firearms_Rifle_Shotgun (7e base 25), handguns
Firearms_Handgun (base 20). The preroll label matches, so the table sees
the truth: `» Tyler Moss — Firearms Rifle Shotgun 50%: rolled …`.

### 2.2 Inventory + equipment meta-commands

`Character.inventory` holds what they carry (weapon display names), seeded
automatically from the equipped weapon — saves written before v2.7.3
migrate themselves on load. At any declaration prompt:

```
inventory        -> [Eleanor Vance — carrying: .32 Revolver | in hand: .32 Revolver]
equip shotgun    -> [Tyler Moss readies the 12-gauge Shotgun.]
unequip          -> [Tyler Moss puts their weapon away.]
```

Equipping what you don't carry changes nothing (and says so). Partial
names work. These inputs never become declarations and never reach the
model.

### 2.3 Weapons are instances

The catalog in charcreate (`WEAPONS`) used to hand out shared objects —
every 12-gauge in the world drained the same ammo counter. The wizard,
pregens, and `equip` now copy the template. And the pregens' sheets are
honest: Eleanor Vance, Firearms_Handgun 50, finally carries her .32.
