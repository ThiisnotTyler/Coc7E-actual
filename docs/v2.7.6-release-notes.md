# v2.7.6 Release Notes — "The Spoiler Channel"

## Field report

A table running in debug mode watched this print mid-scene:

```
[PRIVATE — Elias Lusk] Lusk decides the investigator must not leave.
```

The NPC's private narration — his *scheme* — leaking onto the players'
screen. The user guessed it might be debug-related. It wasn't: the print was
unconditional. Every table was one suspicious NPC away from spoilers.

## The fix

Private narrations are now classified by who owns them:

- **A player's own thoughts** always reach their screen:
  `[PRIVATE — Solo] You recognise that smile from the photograph.`
- **An NPC's thoughts** are keeper-view. They print only when `llm.debug`
  is on, tagged so nobody confuses them with player mail:
  `[KEEPER — Elias Lusk] Lusk decides the investigator must not leave.`

Information hygiene restored: the engine keeps the Keeper's secrets the way
a human Keeper does — behind the screen.
